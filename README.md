# CampusShare - Frontend

## Welcome to CampusShare

A collaborative platform for college students to share and discover academic resources.

## Project info

This is the frontend for the CampusShare application built with modern web technologies.

## How can I edit this code?

**Use your preferred IDE**

Clone this repo and start making changes locally.

The only requirement is having Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

Follow these steps:

```sh
# Step 1: Clone the repository
git clone https://github.com/sharana-basava-3019/Noname-Frontend.git

# Step 2: Navigate to the project directory
cd Noname-Frontend

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```

The frontend will be available at: **http://localhost:8082/**

## What technologies are used for this project?

This project is built with:

- **Vite** - Fast build tool
- **TypeScript** - Type-safe JavaScript
- **React** - UI library
- **shadcn-ui** - Component library
- **Tailwind CSS** - Utility-first CSS
- **React Router** - Client-side routing
- **React Query** - Data fetching
- **Axios** - HTTP client

## Features

- ✅ User authentication (register/login)
- ✅ Resource upload and management
- ✅ Advanced search and filtering
- ✅ Leaderboard system
- ✅ User profiles
- ✅ Resource download tracking
- ✅ Rating and review system

## Getting Started

1. Start the backend server on `http://localhost:3000`
2. Run `npm run dev` to start the frontend
3. Open http://localhost:8082/ in your browser

For detailed API integration information, see [API_INTEGRATION.md](API_INTEGRATION.md)
